# Trabalho bingo

Trabalho Prático da Matéria Algoritmos e Técnicas de Programação

Foi passado para os alunos da PUC Minas produzirem o famoso jogo BINGO, na linguagem C# para aprofundar os estudos e colocar em prática o que está se vendo nas aulas de ATP. Esse trabalho foi feito totalmente por mim, sem uso de Inteligência Artificial. Com esse código consegui a nota total no trabalho prático.
